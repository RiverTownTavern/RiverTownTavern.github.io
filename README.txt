RIVER TOWN TAVERN — WEBSITE DEMO (by NextDay Digital)

Open index.html in any browser to preview.

EVERYTHING EDITABLE LIVES AT THE TOP OF assets/js/main.js:
  hours       -> e.g. Monday: ["12:00","24:00"]  (turns on the live "Open now" badge)
  weekly      -> weekly lineup (feeds the home cards, "Tonight" banner and events calendar)
  steakNight  -> price + which night
  events      -> upcoming events; they hide themselves after the end time, and the countdown + "Add to Calendar" update automatically
  facebook / email -> footer link + contact form

Confirm with the owner: hours, which night is steak night, membership details, menu prices.
Hosting: upload the whole folder to GitHub Pages / Netlify / any host. No build step.
